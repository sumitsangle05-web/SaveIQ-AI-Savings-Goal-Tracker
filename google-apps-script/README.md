# SaveIQ – Google Apps Script Deployment Guide

This guide walks you through deploying **SaveIQ – AI Savings Goal Tracker** natively on Google Workspace using **Google Sheets**, **Google Apps Script**, **Groq AI (LLaMA 3.3-70B Versatile)**, and **Gmail Services**.

---

## 🚀 Key Features Built-in

1. **Google Sheets as Cloud Database**: Automatically creates and manages:
   - `SaveIQ_Goals`: Goal details, targets, current savings, deadline calculations, alert preferences.
   - `SaveIQ_Transactions`: Full ledger of deposits and progress history.
   - `SaveIQ_AI_Logs`: Historical record of AI prompts and financial advice generated by Groq.
2. **Groq LLaMA 3.3-70B Financial Advisory**: High-velocity AI recommendations on budgeting, required daily/weekly pace, and behavioral habit stacking.
3. **Automated Daily Financial Audit**: Evaluates deadline proximity and overdue states.
4. **Proactive Email Reminders via Gmail**: Sends rich, dark-mode formatted HTML email alerts directly to users.
5. **Modern Glassmorphism Web App**: Single-page interactive frontend responsive on mobile, tablet, and desktop.

## 📋 5-Minute Setup Steps

### Step 1: Create a Google Spreadsheet
1. Go to [Google Sheets](https://sheets.new) and create a new blank spreadsheet.
2. Name the spreadsheet: **`SaveIQ Database`**.

### Step 2: Open Google Apps Script Editor
1. In your Google Spreadsheet menu, click **Extensions** > **Apps Script**.
2. Rename the project to **`SaveIQ Engine`**.

### Step 3: Copy Project Files
1. In the Apps Script code editor, replace the content of `Code.gs` with the code in `google-apps-script/Code.gs`.
2. Click the **+** button next to *Files* > Select **HTML** > Name the file `Index` (do not add `.html`).
3. Paste the contents of `google-apps-script/Index.html` into `Index.html`.
4. (Optional but recommended): Click **Project Settings** (gear icon on the left) > check **Show "appsscript.json" manifest file in editor**. In the editor, paste the contents of `google-apps-script/appsscript.json`.

### Step 4: Configure Groq API Key
1. Obtain a free, ultra-fast API key from [Groq Console](https://console.groq.com/keys).
2. In Google Apps Script, click **Project Settings** (gear icon) > scroll to **Script Properties** > click **Add script property**:
   - **Property**: `GROQ_API_KEY`
   - **Value**: `gsk_your_groq_api_key_here`
3. Click **Save script properties**.
   *(Alternatively, run `setGroqApiKey('your-key')` from the Code.gs editor).*

### Step 5: Initialize Database & Automation Trigger
1. In the Apps Script toolbar, select the function `setupDatabaseSheets` from the dropdown and click **Run**.
2. Grant the standard Google permissions (Spreadsheets, Gmail, External HTTP requests).
   - *This will auto-generate the 3 database sheets with headers, sample goals, and color formatting!*
3. Next, select the function `setupDailyAuditTrigger` from the dropdown and click **Run**.
   - *This configures the automated time-driven trigger to audit savings and send email alerts daily at 8:00 AM.*

### Step 6: Deploy Web Application
1. Click the blue **Deploy** button (top right) > **New deployment**.
2. Select type: **Web app** (gear icon next to 'Select type').
3. Fill in the deployment settings:
   - **Description**: `SaveIQ v2.0 Production`
   - **Execute as**: `Me (your-email@gmail.com)`
   - **Who has access**: `Anyone` (or `Only myself` / `Anyone within domain`)
4. Click **Deploy**.
5. Copy the **Web App URL** and open it in your browser!
